# Fiche de présentation (FR)

## Titre
SubnetCalc

## Description courte (max 80 caracteres)
Calculateur de sous-reseaux IPv4, VLSM et regroupement, 100% hors-ligne.

## Description complete

SubnetCalc est un calculateur de sous-reseaux IPv4 simple et rapide, pense
pour les etudiants, administrateurs reseau et candidats aux certifications
(CCNA, reseaux...).

Fonctionnalites :
- Calcul instantane : adresse reseau, broadcast, plage d'adresses
  utilisables, nombre d'hotes, masque et wildcard
- Vue binaire avec distinction visuelle bits reseau / bits hote
- Classification d'adresse (classe A/B/C/D/E, privee/publique/loopback/
  APIPA/multicast/CGNAT)
- Mode VLSM : decoupage en N sous-reseaux egaux, ou allocation optimisee
  selon des besoins en hotes personnalises
- Regroupement (supernetting) : trouve le plus petit bloc CIDR englobant
  plusieurs reseaux
- Saisie rapide au format ip/prefixe (ex: 192.168.1.10/24)
- Copie des resultats (texte ou CSV)
- Theme clair/sombre

Aucune connexion internet requise. Aucune donnee collectee.
